# Maintenance Skill

## Purpose

Use this skill to keep the project healthy as features grow.

## Best Practices

- Make small, reviewable changes.
- Fix nearby bugs when they affect the task.
- Avoid unrelated refactors.
- Remove dead placeholders when replacing them with real behavior.
- Watch for drift between backend and frontend.

## Project-Start Checklist

- What changed recently?
- Are there dirty files?
- Are failing tests related to the task?
- Does this change affect generated clients?
- Does documentation need an update?

## Common Mistakes

- Reformatting unrelated files.
- Weakening tests to pass CI.
- Ignoring client contract changes.
- Leaving placeholders in production paths.

## Definition Of Done

- Change is scoped.
- Tests verify the intended behavior.
- Build status is known.
- Follow-up risks are documented.
- No unrelated user changes are reverted.
