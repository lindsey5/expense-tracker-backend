# Project Skills Index

Use this folder as a scratch-project guide for the skills Codex should apply before and during implementation.

Each subfolder describes one skill area with:

- Best practices
- Project-start checklist
- Common mistakes to avoid
- Definition of done

Recommended reading order:

1. `product-requirements`
2. `architecture`
3. `api-design`
4. `database-design`
5. `backend-implementation`
6. `testing`
7. `security`
8. `ci-cd`
9. `documentation`
10. `maintenance`
