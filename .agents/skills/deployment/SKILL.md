# Deployment

Use for a change to build promotion, runtime configuration, startup, or remote rollout.

- Discover the target environment, artifact, secrets path, migration sequence, health checks, and rollback capability from repository configuration and operator documentation.
- Check compatibility between the new artifact and existing data, then define verification of every required process after rollout.
- Do not invent a cloud provider or execute a live deployment without authorization and a verified target. Use release-and-rollback for recovery planning.
