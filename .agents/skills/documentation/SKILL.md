# Documentation

Use when updating API, setup, architecture, or operations documentation.

- Confirm behavior in code, tests, manifests, and deployment configuration before describing it. Mark absent or unverified capabilities clearly.
- Copy command names and required configuration keys only from the target repository; never include secret values.
- Update the smallest document that users already consult and keep examples aligned with the current public contract.
