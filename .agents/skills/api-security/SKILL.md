# API security

Use for a security-focused API audit or a change to endpoint exposure.

- Inventory public and protected operations, input boundaries, response fields, cross-origin policy, and logging behavior from the actual implementation.
- Check authentication coverage, authorization, data minimization, injection resistance, secret handling, and abuse controls where applicable.
- Verify controls rather than assuming a package or gateway supplies them. Test a concrete misuse path and keep findings distinct from routine code-review style issues.
