# Database queries

Use for filtering, pagination, aggregation, raw queries, or query rewrites.

- Find the repository's data access pattern and existing query helpers. Scope user-owned records using trusted identity, including counts and aggregates.
- Keep filters, date ranges, ordering, and pagination totals consistent. Parameterize values in raw queries and return only needed fields.
- Inspect indexes and measure a slow path before optimizing; use performance-optimization for broader performance work.
