# Authentication

Use for signup, login, credential recovery, session, or token behavior when present.

- Discover the implemented identity provider, credential storage, session or token mechanism, and trust boundaries before editing.
- Protect secrets and credentials in storage, responses, logs, and tests. Preserve expiration, revocation, and account-state checks supported by the system.
- Test valid, invalid, expired, and replayed credentials as relevant. Use authorization for what an authenticated identity may access.
